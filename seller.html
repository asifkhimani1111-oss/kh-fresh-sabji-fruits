દુકાનદાર પેનલ - તમારી દુકાન જાતે ઉમેરો

1. તમારી દુકાન ઉમેરો

ફોટો પસંદ કરવા માટે ઉપર દબાવો. મોબાઇલમાં કેમેરા અથવા ગેલેરીનો વિકલ્પ મળી શકે છે.

તમારી દુકાનની અરજી Admin મંજૂર કરશે. મંજૂરી પછી તમે પ્રોડક્ટ ઉમેરી શકશો.

2. પ્રોડક્ટ ઉમેરો

પ્રોડક્ટનો ફોટો પસંદ કરો. ફોટો અપલોડ થયા પછી તેની લિંક આપમેળે સેવ થશે.

3. દુકાન અરજી ID

દુકાનની અરજી મોકલ્યા પછી મળેલો ID અહીં દેખાશે. તેને સાચવી રાખજો.

મહત્વપૂર્ણ:
1. દુકાનની અરજી Admin પાસે જશે.
2. Admin મંજૂરી આપ્યા પછી જ પ્રોડક્ટ ઉમેરી શકશો.
3. પ્રોડક્ટ પણ Admin મંજૂર કર્યા પછી ગ્રાહકોને દેખાશે.
4. દુકાન અરજી ID સાચવી રાખજો.
